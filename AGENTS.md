# RiffLoop project instructions

## Current scope

- Develop and test the iOS app only, targeting the user's iPad mini 6.
- Keep the Android app unchanged unless the user explicitly requests Android work.
- Keep new score recognition and editing isolated from existing practice playback and saved projects.
- Validate string, fret and rhythm preservation; a generated file or placeholder alone does not prove recognition accuracy.
