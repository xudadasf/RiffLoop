# iPad mini 6 真机验收清单（0.24.3 / build 35）

本清单用于把 `RiffLoop-iPad-0.24.3-unsigned-arm64.ipa` 覆盖安装到 iPad mini 6 后逐项验收。
每项结果记为「通过 / 失败 / 未测」，失败项附一句现象描述（画面、声音、复现步骤）。

## 0. 安装前：确认真机当前版本

1. 打开 iPad「设置 → 通用 → iPad 存储空间」，点 RiffLoop，记下右侧「版本」数字。
2. 打开 RiffLoop 首页，记下显示的签名到期时间和剩余天数（若有）。

## 1. Sideloadly 覆盖安装（不要先卸载旧版）

1. 用 USB 连接 iPad 与 Windows，iPad 上点「信任」；iPad 屏幕保持点亮。
2. 打开 Sideloadly，把解压好的 IPA 拖入：
   `output\release-0.24.3-build35\RiffLoop-iPad-0.24.3-unsigned-arm64.ipa`
3. 选择这台 iPad 和之前使用的同一个 Apple 账号；**不要启用修改 Bundle ID**（保持 `com.riffloop.prototype`）。
4. 启用 **Automatic Refresh**，点击 Start，按提示完成 Apple 登录/双重认证。
5. 等待 Sideloadly 显示完成；在 iPad 上直接覆盖安装。
6. 打开 RiffLoop → 首页点「重新检测」，确认签名到期时间已延后，且旧文件/设置还在。

## 2. 文件与恢复

- [ ] Files 中能看到「在我的 iPad / RiffLoop」下的 `PDF`、`视频`、`GP` 三个子文件夹。
- [ ] 之前导入过的 PDF/视频/GP 文件仍在，首页最近项目仍在。
- [ ] 打开一个旧视频或旧 PDF，上次的播放位置/页面位置仍被恢复。

## 3. 视频练习

- [ ] 导入一个本地 MP4（120 BPM 素材优先），能显示时长并播放、暂停、拖动。
- [ ] `Set Beat 1` 后 Quarter click 能贴合素材第一拍；Eighth/Sixteenth/Triplet 密度正确。
- [ ] BPM 输入限制 30–300；±1/±5 快捷按钮可用。
- [ ] 训练模式：普通节拍 / 基础鼓机 / 只响反拍等可切换且听感正确。
- [ ] 屏幕拍点提示随节拍闪烁；逐拍重音可设置。
- [ ] A/B 循环（1–2 小节）连续 50 次，每轮第一声 click 与素材瞬态的相对位置没有明显漂移；1.0× 和至少一个非 1.0× 速度各测一次。
- [ ] 循环中暂停再恢复，节拍重新贴合；拖动进度后恢复仍由 Beat 1 决定相位。
- [ ] 播放中切换 BPM/细分/速度，没有旧排程残留声。
- [ ] 播放中进入后台再返回，可以明确暂停并重新播放，没有残留声。

## 4. PDF 练习

- [ ] 导入 PDF，可翻页、缩放，退出重开仍记住页面位置。
- [ ] 深色控制浮层显示约 4.5 秒后自动收起，保留「控制」唤出按钮。
- [ ] 节拍器面板可收起/展开，独立音量可调。
- [ ] 绑定一个本地伴奏后可播放、暂停、停止、更换、移除；变速、音量、A/B 循环可用。
- [ ] 录制一段「翻页/滚动」轨迹后，按伴奏或独立节拍器时间能自动跟谱；手动触碰暂停自动跟随。

## 5. Guitar Pro 练习

- [ ] 导入《此生不换》类 `.gp`，每行 2 小节、约 2 行谱面的布局正常。
- [ ] 第 10、33、34 小节同小节延音目标的括号品位可见（对照 Guitar Pro 8）。
- [ ] 普通轻点谱面移动播放光标并开始播放；再点暂停。
- [ ] 长按后拖动可框选循环范围：正向、反向、跨行、回拖缩小、单小节选择均按完整小节；取消手势不覆盖旧范围；靠近上下边缘能继续滚动选择。
- [ ] 内嵌伴奏与合成声音可独立开关/调音量并同步混合；显示轨道变化不会隐式改变静音/独奏；静音/独奏互斥。
- [ ] 节拍器细分随谱面拍号变化；预备拍、整曲循环可用。
- [ ] 播放一半退出该曲再进入，播放位置被恢复（昨天修复项）。
- [ ] 合成音关闭状态下播放不发声（昨天修复「静音 GP 播放」项）；开启后立即有声。

## 6. 签名与续签

- [ ] 首页「无线续签步骤」可打开且步骤与 `docs/IPAD_SIDELOAD.md` 一致。
- [ ] 到期时间显示合理（7 天以内）；两天内到期时出现橙色提醒。

## 7. 回报格式

按小节回报即可，例如：

```text
3. 视频练习
- 导入/播放/拖动：通过
- Set Beat 1 + Quarter：通过
- 50 次循环 1.0×：通过，无漂移
- 50 次循环 1.25×：失败，第 30 轮后 click 明显提前约 50ms
...
```

同时说明测试时使用的输出设备（扬声器/有线耳机；第一轮不要用蓝牙）。
