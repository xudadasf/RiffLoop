# 0.25.75（119）— 四角调整与统一识别设置

框选页点击选中，双击进入调整模式，拖动任一角改变识别范围，松手自动保存。也可用底部「调整区域／完成调整」切换；缩放后仍按原图坐标保存。编号和连接顺序保留，单一删除按钮仍只删除选中框。

「下一步：识别设置」统一设置 BPM、拍号、调弦和区域之间的空白小节，间隔 0–99，0 连续、末尾不追加。新任务默认间隔 1；不再给每个识别框显示独立间隔输入。旧任务若已有不同间隔，打开时保留，填写统一数值后再整体替换。

不再要求逐项点击应用。点「保存」一次提交所有有效输入；点「识别并进入编辑」也会先自动保存。调整连接顺序、采用或排除区域不会丢掉正在填写的设置。无效数值在页面中指出具体字段，不再用“其他尚未应用的输入”反复阻塞。

识别后的核对编辑页，在「小节 / 复制」中输入数量，可在当前小节前后插入空白小节（1–99）；沿用当前小节拍号和局部速度，保留原音符，支持撤销。已有空白小节可选中后删除。
