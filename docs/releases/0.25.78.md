# 0.25.78（122）编辑滚动、前插和技巧修改

## 使用

1. 手指在谱面滑动只滚动，不再换音或拉选范围。单点选音；左下方向按钮换音/换弦，中间“定位”回到当前音符。
2. 要在原音前补内容，先选中原音，点左侧“插入”，再点“前插音符”或“前插休止”。新音符出现待输入标记，右下数字键输入品位，再选时值。原音保留，撤销可恢复。
3. 底部分类添加常用技巧，再点同一技巧可取消。左侧“已用技巧”查看当前音/拍已用内容，逐项修改或取消。
4. 推弦、摇把可选择预设，再改控制点的位置百分比和升降半音；支持 0.5 半音步进。曲线有 GP 兼容性检查，不兼容的修改会保留原曲线并提示。
5. 选范围仍可用“选择”模式点首尾或方向按钮；不支持按住拖选。整段技巧修改作用于已选拍位的所有弦。
6. 试听后点“保存”，仍然更新同一份结果。插入后核对小节时值，不齐也会先保留可编辑草稿。

技巧覆盖和边界见 [核查记录](../reviews/2026-11-17-editor-touch-techniques.md)。本轮不修改识别算法和原练习播放功能。
