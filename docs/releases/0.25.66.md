# 0.25.66 (110) — independent metronome and foreground practice time

- GP has a separate compact independent-metronome entry in the top toolbar. Its
  panel contains only its own transport, BPM, meter, subdivisions, accents and
  volume. The bottom score-metronome panel contains score and count-in settings.
- Independent subdivisions and accents are saved separately across GP files;
  legacy profiles receive independent defaults, without borrowing score settings.
  Volume supports 0–600%, including the native click gain, matching the score
  metronome's selectable range. Playback remains mutually exclusive.
- GP/PDF/video session clocks count foreground active time in the mode, including
  pauses. Background/inactive time and the home screen do not count. Returning
  from background resumes the same visit; leaving and reentering starts a new
  session. File changes within the same visit preserve its clock.
- Home daily history now records these same foreground segments, without adding
  transport playback time a second time. Existing historical totals are retained;
  this version does not attempt to reinterpret earlier playback-only history.
- Home summary durations use `2h 7m` / `7m`; the calendar legend is removed.
  Tapping an elapsed calendar day opens its date and duration down to seconds.

Validation and installation status will be recorded after CI and device checks.
