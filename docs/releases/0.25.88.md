# RiffLoop iPad 0.25.88 (132)

## 阶梯起始阶段

- 阶段信息旁增加「选阶段」，菜单显示各阶段 BPM 和持续秒数／循环轮数；底部及对应设置页都可操作。
- GP 暂停后选择任意阶段，会准备该阶段的完整计时／轮数并回到 A/B 区间起点，按播放才开始。
- 独立节拍器可从指定阶段首拍开始，响／静训练同时从响小节开始。
- 未重新选择时，暂停后继续保留阶段进度。打开曲谱、修改计划或重新启用时仍默认第一阶段。
- 往返模式从所选阶段向末段推进，再按原计划反向循环；GP 与独立节拍器选择互不影响。
- 播放和预备拍期间禁用选择，避免中途切换。控件使用至少 44 点触控高度，阶段文字可换行。

## 验证范围

原生回归覆盖阶段计时、暂停续播、循环方向、非法索引、模式隔离和计划修改；iPad mini 界面测试覆盖菜单选阶段、BPM 显示及按钮位置和触控高度。沿用现有播放、暂停恢复、预备拍及音画同步监测测试。

本次不修改曲谱内容、识别编辑、Android 或持久化文件格式。
