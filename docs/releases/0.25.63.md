# 0.25.63 (107) — GP 重复中断恢复与命令异常归档

## 原因与修改

- GP 网页进程第二次中断时，应用会停止自动恢复并提示重新打开文件，但选谱流程只缓存数据，没有重新加载已失效的网页。现在第二次中断后保留“下次选谱必须重载”的状态；用户重新选择 GP 时先重载网页，新页面就绪后再提交已选谱面。
- GP 命令执行错误、网页桥接返回失败及命令参数编码失败原来只显示弹窗并写普通操作结果，不会触发异常现场归档。现在三类失败都记录为 `gp.command_failed`，保留命令名、错误信息及异常前后的诊断现场。

## 验证

- 真实 WKWebView 集成测试覆盖：首次网页中断自动恢复；恢复后尚未播放时再次中断；重新选择另一份 GP；新页面和播放器重新就绪；随后继续播放。
- iOS CI #147 在修复提交 `db46f50` 上通过，包含 Swift 编译、完整 iPad mini 模拟器测试和截图步骤。
- 本地 GP 播放、预备拍、循环、换谱、音频及已报告问题策略测试通过。

WebContent 被系统终止的根因仍没有同期系统报告。本版本修复的是重复终止后的人工恢复路径，并确保以后出现命令失败时能够导出对应异常现场。
