# 0.25.65 (109) — practice controls candidate

Continues the interrupted 2026-10-15 task from 0.25.64 (108). The final agreed
interaction is to seek and continue playing when tapping a GP score, not pause.

- GP taps retain the viewport when the selected row is visible; selections after
  manual browsing move smoothly. Browsing alone keeps playback running and returns
  to the current row after 3 seconds without interaction. Fitting loops remain
  centered as a group. Long-press range selection is retained.
- Direct practice BPM entry, one-BPM steps, and 0.25–2x presets, constrained by
  alphaTab's effective speed limits. Original tempo-map changes remain proportional.
- Independent GP metronome with its own BPM, beats per bar and volume. Starting
  normal playback stops it; starting it pauses normal playback and leaves the score
  stationary. Its preferences follow the GP mode across files.
- Audio interruptions retain a resume action only for previously running playback.
  Resume requires system permission, the same output and an active app. A temporary
  inactive state can defer recovery until activation; background, manual pause,
  route disconnection and leaving the mode cancel it.
- PDF beat cue omits the unbounded measure count.
- GP, PDF and video show a compact session clock in the navigation toolbar. It
  starts on entering the page and continues during pauses and file changes. A new
  page starts a new session. Existing playback-only history remains separate.
