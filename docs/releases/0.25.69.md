- Preserve the latest explicit seek when alphaTab's delayed pause acknowledgement snaps its cursor to the previous beat.
- Ignore late range-boundary positions after manual pause/stop, preventing them from starting another loop.
- PDF pending accompaniment/follow starts can be cancelled before audio attachment, player readiness or initial seek completes. The accompaniment button reflects a pending playback request. Established independent audio/metronome/follow controls retain their separate meanings.
- USB reconnection still requires manual playback. Existing practice history and volume settings are unchanged.

## Manual update

1. Download the verified [RiffLoop-iPad-0.25.69-unsigned-arm64 artifact](https://github.com/xudadasf/RiffLoop/actions/runs/40811585478/artifacts/12870796563) (GitHub sign-in may be required). Extract the ZIP to obtain the IPA.
2. Connect the unlocked iPad over USB and open Sideloadly. Select the same iPad and Apple account used for the existing RiffLoop. Do not uninstall the old app or change its bundle identifier.
3. In Settings, keep `Anisette Authentication = Remote` and `Signing Mode = Apple ID Sideload`, then confirm with OK. This machine previously hit -80046 with the old authentication mode.
4. Drag the extracted IPA onto Sideloadly's IPA icon and click Start. Enter any Apple verification code yourself. Wait for completion; a downloaded package alone is not an installed update.
5. Confirm the device reports 0.25.69 (113), the original bundle/signer and valid profile, and that existing files and practice history remain. Recheck pause/stop, rapid replay, paused seek and PDF cancellation on the physical iPad.
6. After successful verification, remove the manually downloaded ZIP/IPA and other temporary installation files if no local copy is wanted. Git retains source and verification records; Actions artifacts currently have 30-day retention and can be rebuilt from the recorded source commit.
