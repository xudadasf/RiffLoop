# 0.25.74（118）— 方框点选、编号与间隔

在「识别与编辑」中打开素材后，点击方框即可选中，橙色表示当前选择。页面只保留一个「删除选中框」按钮，确认后删除该框，其余框会重新连续编号；取消不会删除。

选中框后可修改「编号」和「后接空白小节」，点击「应用」保存。编号覆盖整份素材，PDF 翻页也不重复。改号表示移动到该位置，其他框自动顺延。间隔是 0–99 个空白小节，0 表示连续连接，最后一个框不追加空白小节。间隔跟随框本身，改号不会交换或丢失间隔。

「画框」打开时拖动新增，点击已有框仍可选中。关闭画框后可以滚动；放大、缩小不改变保存的坐标。未应用的输入需先应用或恢复，避免切换框、翻页或继续识别时丢失修改。

点「下一步：识别设置」创建计划，计划沿用保存的编号顺序与间隔。可继续设置 BPM、拍号和调弦，保存任务后「识别并进入编辑」。多个素材拼接仍按素材名称排列，每份素材内部按其方框编号排列。

旧区域默认沿用原页序、画框顺序和 1 个空白小节，原图片和区域坐标不改写。已保存的识别计划保持原有顺序、间隔和其他设置；需要使用新方框设置时创建新计划。本次未修改 Android、练习播放器、原曲谱或练习记录。
