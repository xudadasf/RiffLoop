# 0.25.77（121）技巧与插入操作

## 操作
1. 点六线谱中的品位或空弦位，再点底部分类。常用技巧直接应用，再点取消；长工具条可左右滑动。
2. 「效果」：在起音上点“击勾弦 H/P”或“滑音”；「节奏」：在后一个同弦同品音上点“延音”。
3. 「拍」：“插入拍”放在当前拍前，“添加拍”放在后面。光标自动选中新空拍，输入数字即成音符；也可留作休止并选时值。
4. 右下删除：先删除光标所在弦的音；该拍无音时再删，才删除整个拍位。−/+ 缩短/延长时值，圆点切换附点。
5. 左下方向键或中心滑动换弦/换拍；Alt 按小节移动；Shift 选范围后可整段应用技巧。音符品位不因选范围而改变。
6. 两位品数不用抢速度：先点 1、2 或 3，再点第二位；移动光标会结束该次数字输入。上下换弦可输入和弦。
7. 播放验证后点“保存”，继续更新同一份结果。无需重新识别。原有未齐时值保留草稿、GP 校验提示仍有效。

范围：本轮改 iOS TAB 输入与技巧操作，五线谱继续联动显示；不等于复制 Reflow 的全部功能。未调整识别算法和原练习播放逻辑。
