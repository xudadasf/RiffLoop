# 0.25.72（116）— 离线 TAB 识别与电吉他编辑

主页「识别与编辑」内导入截图、照片或 PDF，框选需要识别的六线谱区域，再在区域计划中调整连接顺序、空白小节间隔、BPM、拍号和定弦。保存计划后点「识别并进入编辑」。识别在设备内完成，模型随安装包提供。

识别优先保留数字和弦位；看不清或无法推断的节奏标为待核对，失败区域仍有可填写的小节。停止识别会保留已完成内容。没有 BPM 或拍号时可使用默认 100 BPM、4/4，也可先手动设置。

编辑时先点弦上的格子，再按下方数字键输入品位；连续输入 1、3 得到 13。同一拍位在其他弦输入数字即为和弦。「前插休止／后插休止」会新增拍位，「改为休止」改变当前拍位。下方可选时值、附点、连音，支持撤销、重做和复制粘贴。

「技巧」作用于当前弦音符或当前拍位，可设置延音、击勾弦、滑音、推弦、摇把、揉弦、闷音、死音、泛音、点弦、震音等。延音选后一个同弦同品音；击勾弦和连贯滑音选起音，后面需要同弦目标音。可打开原图核对及谱面预览。

随时保存草稿，稍后从「电吉他草稿」重新打开。时值完整后「生成 GP 副本」加入 Guitar Pro 练习列表。原素材与旧练习文件保持独立。确认修正结果已保存为 GP 后，可在草稿列表点「清理草稿」删除编辑中间稿；此按钮保留原素材和 GP。

当前以六弦 TAB、单声部草稿为范围。复杂节奏和技巧需要人工补充；纯五线谱与已有 GP 的直接编辑尚不支持。交替颤音的非十六分速度受当前 GP 导入库限制，导出会明确提示。草稿可保存 512 小节，单次导出限 128 小节/4096 拍位。
