# 0.25.76（120）谱面编辑与试听

识别结果直接显示五线谱与六线谱。点六线谱选择弦位和拍位，右下数字键输入品位；左下可按弦、拍、小节移动。底部修改时值、附点、连音、休止和插删拍，左侧「技巧」设置电吉他技巧，「小节 / 复制」调整结构和局部空白。

右下「播放 / 暂停」试听当前编辑结果，「回到开头」停止并复位；支持全曲循环。编辑、离开页面、后台或音频中断会暂停，恢复后手动播放。顶部可看原图、改曲名/BPM/拍号、缩放或切换阅读。

点一次「保存」即可保留编辑并更新同一份练习 GP。再次保存或改曲名不新增 GP；同素材、区域顺序、间隔和识别设置再次识别会打开此前结果，保留人工修改。旧版已经生成的历史副本不自动删除。

未补齐时值或导出校验失败时，仍保存可继续修改的编辑内容，并明确提示练习谱尚未更新。未知品位在编辑稿中保留为“?”，试听和 GP 中使用静音占位，不作为空弦音播放。外部改过的同名 GP 不自动覆盖，避免丢失其他编辑。

本版只修改 iOS 的识别编辑工作区。原 GP/PDF/视频/节拍器及 Android 代码未改。
