# 0.25.73（117）— 识别编辑与异常记录写盘修复

包含 [0.25.72 的全部离线 TAB 识别和编辑功能](0.25.72.md)：截图/照片/PDF 框选、顺序及间隔设置、BPM/拍号、失败占位、生成后进入触摸编辑器、技巧编辑、GP 副本及草稿清理。

本次根据 USB 读取的 iPad 异常报告，修复正常诊断采样重复写入全部状态的问题。正常检查点改为 15 秒批次并保存状态差量，异常及前后台切换仍立即保存。可控 90 秒测试的序列化写入由 2,281,200 字节降至 154,626 字节，减少约 93.2%；完整异常参数及状态继续保留。突然杀进程时可能丢失最后 15 秒普通诊断采样，不影响曲谱、练习历史的保存策略。

四次系统音频中断均及时暂停，仍由用户手动继续；本次没有添加自动恢复播放，也没有改变现有播放逻辑。
