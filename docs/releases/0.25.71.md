# 0.25.71（115）— 手动节奏草稿编辑

在主页「识别与编辑 → 新建与编辑草稿」中，可以新建六线谱草稿，逐小节填写弦位、品位、休止、和弦、附点与三连音。可以保存未完成内容，关闭后重新打开继续编辑；小节拍数完整后，生成独立 GP 副本并打开练习或分享。

新草稿默认标准定弦、4/4、100 BPM。每根弦留空表示不发声，0 表示空弦，全部留空是休止。新小节中的整小节休止可直接点击修改。在名称或速度输入下方点「应用名称和速度」后再保存。

本次新增的是手动草稿页面。图片自动识别、已有 GP 的直接编辑、延音线、滑音和击勾弦等仍未接入。图片/PDF 素材仍可独立导入、预览和手动框选；不能将草稿测试通过视为自动识谱已经完成。

## 保护已有内容

未保存时离开会提示；保存或生成失败后保留输入。草稿有其他窗口修改时可另存，避免覆盖。每次生成 GP 使用新的文件名和练习身份；原曲谱及其设置保持独立。超出导出容量的草稿仍可保存，不截短内容。

现有 GP/PDF/视频/节拍器实现没有改动，USB 设备恢复后仍须手动继续播放。
