# iPad 候选版 0.25.53（97）

状态：完整回归与发布准备中，尚未安装。稳定标签 `v0.25.51` 不变。统一需求：[Issue #1](https://github.com/xudadasf/RiffLoop/issues/1)。

## 本轮行为

- GP/GPX/GP3–5、PDF、MP4/MOV/M4V 声明为可打开文档。外部文件复制到对应库并进入练习；同名文件另存，保留原文件和原练习记录。
- 三种模式打开文件后保持屏幕常亮，包括暂停看谱；退出页面或进入后台释放请求。
- 视频、PDF、GP 合成/伴奏/预备拍音量可到 200%，GP 节拍器到 300%。原有音量数值保持不变，增益作用在实际 PCM/合成器上。
- GP 换谱等待当前谱面的就绪回执；播放器拒绝启动时按钮仍可重试；重新发送倍速和音量等设置。手动中断预备拍后恢复前重置已丢弃音频的计数，回到原谱面位置。自动循环仍按 B→暂停→A 回执→一小节预备拍→A–B 执行，预备拍期间显示 A 点。普通循环不显示提速轮次分母。
- PDF 节拍器可独立开关；开始记录自动启动节拍器并保存起点的小节/拍号提示；有有效记录才能跟谱，静音时仍可跟谱。用户在合适拍点开启跟谱时不重启已经运行的节拍器。
- iPad mini 底部工具布局纳入实际截图复核，处理按钮文字换行和 GP 工具挤出屏幕的问题。

## 诊断与验证依据

1. 真实 AlphaSynth 中“播放被拒绝却留下播放意图”和旧谱就绪状态误用回归先失败，修正后通过。
2. 真实 AlphaSynth 在预备拍预缓冲后暂停，WebAudio 丢弃缓冲而合成器仍等待该批样本完成，导致恢复无法进入主谱面。生产控制器的中断恢复测试先失败，修正后连续 20 次通过。
3. 真实 WebKit 使用随测试生成的 GP 文件，在两份文件间切换、0.9×倍速、重新选区、预备拍中暂停后恢复，并完成每段两轮循环。
4. 真实 AVPlayer 验证冷启动、暂停定位、快速 ±5 秒跳转、循环末尾，以及视频两档各 50 轮。PDF 验证独立节拍器、记录提示、静音跟谱和 50 次跟谱回跳。
5. 文件导入校验扩展名、同名另存和原文件字节保留；页面截图与常亮/退出释放同时检查。SwiftUI 独立测试窗口需要传入实际 Scene 前台状态，并通过移除 SwiftUI 页面验证退出生命周期。
6. [CI 33945156173](https://github.com/xudadasf/RiffLoop/actions/runs/33945156173)（`5850ee5`）126 项 Swift 测试全部通过；五套 Node 回归、7 项发布安全用例和 6 项 IPA 校验器测试通过。GP 工具区最后的宽度限制完成后，最终精确提交的 CI、IPA 和 SHA256 待发布阶段补充。
