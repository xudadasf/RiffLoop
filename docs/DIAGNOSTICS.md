# iPad 异常复现记录

首页 → **异常复现记录** → 选择出问题的异常现场 → **生成这一会话的复现包**。ZIP 保存在 Files → RiffLoop → 异常复现包，可通过分享按钮导出。系统卡死时无需操作记录页：下次启动后导出上一次会话即可。此功能只在设备本地记录，分享前不会上传。

## 包内证据

- `manifest.json`：App 版本、系统版本与 build、硬件型号、屏幕、语言、时区、素材清单与 SHA256、缺失状态、日志轮转计数、记录错误数。
- `events-*.jsonl`：带递增序号、墙钟时间、启动后秒数的操作、参数、操作前后状态、异步命令结果、面板/文件列表切换、播放位置采样、配置恢复/保存记录。`operationID` 对应 begin/result；`method_returned` 仅表示 Swift 方法返回，真正异步结果需核对桥接事件和播放器状态。
- `materials/`：平时只记录输入指纹（GP 对实际提交的 Data 计算 SHA256），异常触发后才复制关联素材，并与加载时的指纹核对。异常保存前后输入变化、被删除或超限会明确报告，不能视为完整复现。GP 内嵌伴奏随原 GP 保留。
- `metrickit-*.json`：系统提供的诊断原文，可能包含崩溃、卡死堆栈；以报告内部时间关联原会话，不能将到达时间当成发生时间。
- `重放步骤.txt`：环境准备、素材导入、设置恢复以及带时间间隔的人工重放清单。当前不自动执行操作、不自动修改练习库。

## 如何还原一次异常

1. 检查 `materials.status`、`droppedEvents` 和 `recordingErrors`。缺少任一前提时，先补素材或重新采集；不要把不完整包标为“保证复现”。
2. 安装对应版本，使用尽量相同的 iPad、iPadOS、横屏方向、音频路由与输出配置。
3. 导入素材并核对 SHA256。依据 `profile.restored` 与首次操作的 `state` 恢复设置和播放位置；`profile.default` 表示使用该版本默认值。不要用事后保存的配置覆盖最初条件。
4. 按 sequence 及 elapsed 重做操作；例如切谱 → 播放 → `gp.tap_panel` sound → `gp.tap_files` → `library.select`。对照每一步的 result 与状态，定位首次偏离位置。
5. 若 `gp.command.*` 有 begin 无 result，检查 WebKit 是否终止、JS 报错或主线程阻塞；`gp.load_until_player_ready` 的超时只表示缺少完成信号，并非已确定根因。

## 限制与性能

串行日志队列独立于素材复制和 ZIP 导出队列，UI 不执行日志文件写入或素材哈希。主线程心跳每 250 ms 检查，前台约 750 ms 无响应记录一次卡顿，恢复时记录持续时间；后台/失去活跃状态会重置心跳，防止把系统暂停当成卡死。异步操作前台超过 10 秒尚未返回会留下超时线索。应用仍响应但逻辑状态错误的情况可手动标记现场。

只持久保存异常前最多 60 秒/512 KB 和异常后 15 秒。正常动作放入内存滚动缓冲，每 3 秒覆盖一个最多约 512 KB 的闪退检查点，不累计保存正常历史、不复制正常使用的素材。重新启动时删除无异常的旧会话；最多保留 3 个会话，每个最多约 2 MB 异常日志及 128 MB 关联素材（同内容只存一份）。播放位置每秒采样，GP 滚动停止后 250 ms 记录位置；语义动作包含精确参数，但不会保留每个原始触摸点。PDF 录制轨迹在配置保存/恢复事件中保留，录制中尚未保存的连续触摸轨迹不保证完整。日志超限会标明丢弃步骤；素材超限会要求提供原文件。已导出 ZIP 由用户管理。

`observedLoadGeneration` 是消息到达时 JS 的当前加载代次，并不能证明异步 alphaTab 回调属于哪个源加载。关联时同时看原生 loadID、文件和时间，不据此断言竞态已经排除。

未正常结束的前台会话只标记为 unknown；强制退出、断电和系统回收也会如此。系统报告可能延迟或缺失，突然断电/进程被立即杀死可能来不及写入最后几条记录。异常段之间的正常时间被省略，sequence 不连续本身不代表记录损坏。闪退恢复可能缺少最近 3 秒尚未写入检查点的操作。操作时间在入队前捕获，磁盘排队不会被误算为用户操作间隔。线程调度、内存压力及外设条件不能由日志完全控制，所以本功能提供核对复现条件的证据，不能承诺所有偶发异常都必然重现。

验证：`ReproductionStoreTests` 覆盖参数/状态跨启动恢复、未正常结束分类、心跳背景隔离、素材指纹/异常快照/预算缺失标记及正常操作不归档、导出与日志轮转计数。发布还须通过仓库既有 Node 回归和 iOS CI。
