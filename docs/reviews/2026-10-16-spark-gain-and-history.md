# Spark MINI 音量检查与首页时长气泡

## 问题与证据

用户确认使用 USB 连接 Spark MINI，并授权在合理范围内尽量保留宽调节范围。保留 0–600%，不继续扩大，不主动调高已有设置。

用户反馈 iPad 接 Spark MINI 后音量较小，要求确认 600% 是否有效、过量增益是否有设备风险，并将首页日期详情改为固定位置的小时/分钟小气泡。

0.25.66 的原生独立节拍器确实把增益应用到 PCM，但随后硬截断到 ±1。按生产源码中的 48 kHz、35 ms 强拍波形复算：

| 设置 | 相对 100% 的点击窗口 RMS 增幅 | 被硬截断采样比例 |
| --- | ---: | ---: |
| 100% | 0 dB | 0% |
| 150% | 3.13 dB | 5.42% |
| 200% | 4.74 dB | 12.74% |
| 400% | 7.36 dB | 35.48% |
| 600% | 8.38 dB | 51.01% |

这是源码波形的离线计算，不是音箱声压测量。它说明增益有效但高档存在收益递减与硬削波。100% 强拍峰值已约为 0.936；因此不能把 600% 理解为六倍硬件功率或听感。

同时使用生产 GP 事件生成代码、内置 Sonivox 音色、真实 AlphaSynth 渲染器和生产输出限幅曲线测量前 100 ms：

| 谱面设置 | RMS | 限幅后峰值 |
| --- | ---: | ---: |
| 100% | 0.057724 | 0.427046 |
| 200% | 0.115429 | 0.847523 |
| 400% | 0.215993 | 0.979889 |
| 600% | 0.285570 | 0.980000 |

两类音色、衰减和测量窗口不同，不能直接比较这两表的 RMS 大小；它们只说明各自调节范围确实生效。

## 修改

- 原生点击声改用与 GP 输出一致的柔和限幅曲线，低电平保持线性，峰值渐近 0.98，避免直接硬截断。仍有高增益非线性失真，不能宣称完全无失真或保护任何外接设备。
- 保留 0–600%、用户已有音量、iPad 系统音量与外接设备设置；不自动把实际音箱开到最大。
- 其他视频/伴奏 PCM 增益路径本轮不变。
- 首页记录卡片右上角固定小胶囊显示 `nh ym`，隐藏日期/秒数，不使用系统 popover；选择格子有边框，再点取消。日期仅保留在无障碍格子名称中以区分不同日期。

## 外接设备边界与参考

- [Spark MINI 官方声音排查](https://help.positivegrid.com/hc/en-us/articles/45070569965709)要求检查 Music 音量；MINI 音乐输入优先级为 AUX > 蓝牙音频 > USB。软件增益无法绕过 iPad 输出音量或音箱功放能力。
- [Spark 蓝牙音量排查](https://help.positivegrid.com/hc/en-us/articles/8280403753229-No-Sound-from-Spark-Troubleshooting)要求同时检查设备音量与 Music 旋钮；该页其他机型输入优先级不套用到 MINI。
- [Shure P300 指南](https://www.shure.com/en-US/docs/guide/P300)说明应避免数字输出到达 0 dBFS 削波。
- [Rockford Fosgate 对削波的说明](https://rockfordfosgate.zendesk.com/hc/en-us/articles/23181772282395-What-is-clipping)区分失真与过量功率：高功率过载可能损坏扬声器。不能仅由软件百分比判断硬件是否安全。
