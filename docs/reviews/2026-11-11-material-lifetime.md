# 制谱素材与区域记录的操作边界

- 同一应用进程内，导入发布、素材副本删除和区域记录读写使用共享锁。区域编辑器打开素材时绑定该路径的进程内代次，删除或重新导入后，旧编辑器不能继续保存；预览完成后会再次核对代次。
- 素材副本删除与其区域记录清理在同一个锁内顺序进行。素材删除成功、清理失败时，界面明确提示：如果重新导入同名且内容相同的素材，可能看到残留的旧区域，需要人工检查。
- 这不是跨进程的事务。应用在素材删除成功但区域记录清理完成之前意外终止，也可能留下旧区域；应用外直接替换素材不受进程内代次保护。当前没有持久化素材身份、自动发现残留或自动恢复机制。
- 新增覆盖删除后的旧窗口、同名同内容重新导入、渲染期间替换、区域清理失败的测试。提交时须实际运行 iPad 模拟器测试，不应仅凭这些测试存在就声称已验证。
