# Phase 0 真机测试清单

## 测试前提

- iPad 扬声器或有线耳机；第一轮不要使用蓝牙。
- 一个节拍清晰、已知为 120 BPM 的本地 MP4。
- 最好同时准备一个带可见闪光/鼓点瞬态的校准视频，便于录音或录像逐帧复核。

记录每次测试的 iPad 型号、iPadOS 版本、输出设备、素材编码、播放速度和 A/B 时长。

## 基础功能

- [ ] 从 Files 导入 MP4，能显示时长并播放。
- [ ] 播放、暂停、拖动和 ±5/10 秒工作。
- [ ] 在实际第一拍点击 `Set Beat 1`，Quarter click 能贴合素材。
- [ ] Quarter、Eighth、16th、Triplet 的密度正确。
- [ ] BPM 输入被限制在 30–300。
- [ ] A 点早于 B 点；非法 B 点会被拒绝。

## 50 次 Loop 主测试

建议 A/B 选择 1–2 小节，便于快速完成：

- [ ] 1.0×、120 BPM、Quarter，连续 50 次。
- [ ] 0.5×、120 BPM、Eighth，连续 50 次。
- [ ] 1.25×、120 BPM、Quarter，连续 50 次。
- [ ] 每轮第一次 click 与素材瞬态的相对位置没有持续向前或向后移动。
- [ ] 第 1、10、20、30、40、50 轮记录主观结果。

## 重同步测试

- [ ] Loop 中暂停再恢复，节拍重新贴合。
- [ ] 拖动到任意位置后恢复，节拍相位仍由 Beat 1 决定。
- [ ] 播放中切换 BPM 和 Subdivision，没有旧排程残留声。
- [ ] 播放中切换速度，下一次启动后重新对齐。
- [ ] 修改 Beat 1 后立即使用新 Offset。

## 判定

通过：50 次后没有“越来越偏”的趋势；单次固定偏差小到听感可接受。

不通过时先分类：

- 固定偏差：优先调查设备输出延迟、click 音色包络和用户 Offset。
- 逐轮增加：优先调查 host time 映射、播放速度换算或 Loop 锚点是否真正重建。
- 偶发跳变：优先调查精确 Seek、preroll、素材关键帧和设备负载。

未通过前不要开始 Phase 1 的项目保存、Marker 或复杂 UI。
