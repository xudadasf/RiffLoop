# Domain docs

RiffLoop uses a single-context documentation layout.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant decisions under `docs/adr/` when the directory exists.
- If either is absent, continue without treating the absence as an error.

Use the vocabulary defined in `CONTEXT.md`. If a proposal conflicts with an existing ADR, identify the conflict explicitly rather than silently overriding it.
