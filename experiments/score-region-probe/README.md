# 六线谱分区评测基础（独立实验）

本目录生成内存中的合成页面和纯六线谱真值，并按区域逐项统计完整匹配、漏框、截断、碎框、误合并、过大框、误框和重复框。它不读取或上传素材，不连接 RiffLoop，也不含自动识别算法。

```powershell
python -B -m unittest discover -s experiments/score-region-probe -p 'test_*.py'
```

框采用左上角原点、右下边界不包含的像素坐标。匹配要求候选框覆盖真值面积至少 98%，且不能同时显著覆盖第二个真值；同一个候选最多匹配一个真值。覆盖不足但达到 15% 时标记截断，多个候选分别覆盖该行时还标记碎框；一个候选覆盖两个真值各至少 15% 时标记误合并，不得记为正确。

仅覆盖一个真值时，若候选面积大于真值面积的 2 倍，单独标记为过大框，也不记为成功；刚好等于 2 倍仍通过面积条件。可在 `assess(..., max_area_ratio=...)` 中调整，且必须为不小于 1 的有限数。若同时覆盖多行，优先标记为误合并，避免重复分类。面积比例只是一种留白代理指标，无法判断框中是否包含文字、图画或演奏符号；允许多少边距仍需依据标注与真实素材检验。所有阈值仅用于实验，错误类型可以同时出现。

本实验的合成线条不包含真实谱的全部字形、背景、拍摄畸变和教材图文，也不能验证实际识别率。正式候选方案还需要独立的真实纯六线谱边界标注、分段核对、真机性能和用户确认，才可以接入。
