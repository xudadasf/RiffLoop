# 整行漏检与密集双位品位修复（2026-11-03）

用户《恋人间奏》截图原有 3 行、8 小节，旧实际结果只有 2 行、5 小节、23 个数字位置。不是 BPM 或拍号缺失造成的。此前四张相近字体的图片通过，没有覆盖这次的整行漏检和密集数字问题。

## 原因与修复

- 第一行上方短笔画与弦间距相近，旧检测器在检查六根线之前就按“七线网格”排除整行。现在相邻额外横线也必须覆盖本谱行至少一半宽度，才能作为第七根线；真正的七线网格和五线谱仍排除。上下两侧的短线均有独立合成回归。
- 第 4 小节一弦 13 品原始 OCR 分数 0.78064，被过滤。三个微移位置都读为 13，较好位置分数 0.86301。现在仅在三个读数一致、初始分数至少 0.7、较好位置至少 0.85 且有足够提升时允许恢复，并始终标为待核对。分数不是正确率。
- 第 3 小节相邻 11、13 的字符距离落进统一合并半径，形成非法的 1113。现在仅对超长数字组中有明显较大字符间隔、且分开后均为合法品位的情况拆组；等距歧义保留，不按固定两位数强行切分。
- 第 2 小节二弦 6、11 在位置重试后被替换成 6、1，因为少一个字符反而提高了平均分数。现在尚不可靠的重试结果不能仅凭分数提升折叠重复数字；强读数去除邻弦边缘噪声的原能力保留。
- 仍未达到阈值的数字保留文本、弦号、小节、裁剪框、分数和三次读数，在结果页对应小节直接显示候选及“尚未写入 GP”。不再需要展开日志才看得到候选，也不把弱候选当作已确认音符自动写入。
