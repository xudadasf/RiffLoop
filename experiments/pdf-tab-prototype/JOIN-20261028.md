# 多文件拼接与空白分隔

在桌面入口添加 PDF / 截图，按 Ctrl 或 Shift 选中至少两份原文件，点击“拼接所选文件…”。设置谱名，用“上移 / 下移”调整顺序，逐份设置“之后空白小节”。0 表示直接连接，1–99 表示插入相应数量的完整休止小节；最后一份不追加。

点击“开始拼接”会从原文件重新识别，另建结果目录，列表新增“拼接 GP”结果。原来的单份结果保留，已在 Guitar Pro 中手工修改的内容不会带入新草稿。结果页显示各片段在合并 GP 中的小节范围，并链接到各片段的原谱和疑点；问题列表按合并后编号显示，原小节号也保留。

空白小节沿用前一片段末尾的速度和拍号，播放时会产生相应休止；下一片段保留自己的拍号和速度。定弦不同的片段会阻止合并。任一片段失败或用户中途停止时，不导出缺段的拼接 GP，已完成的单份结果仍在结果目录中。

截图应按完整小节切分，避免重复截入同一小节；本功能不会自动去重重叠内容，也不修复跨截图的半小节。原有图片识别和 GP 草稿限制仍适用。

实现：`desktop_join_dialog.py` 负责排序 / 分隔，`desktop_join.py` 调用既有识别并组合数据，`gp-draft-export.cjs` 延续读回验证，保留图片时值问号与低置信度提示。未改动 iOS / Android。
