## 根因和修复

只读探针保留真实 PDF 的形状、文字和节拍，在诊断副本中绕过 X 来源过滤后，上述 2 处均可由已有斜线/连奏弧/标签规则确认，证明几何信息并未丢失。原始预测和素材未修改；生产修复也没有把 X 伪装成 0 品。

共享规则允许普通单音 X 作为显式连奏滑音来源，继续要求相邻节拍、同弦、唯一连奏弧、sl. 标签、目标为实音，且必须存在唯一可见斜线。由于 X 没有可读品位，线段方向不能与虚构的源音音高比较；只在这一来源类型上按连接几何验证。缺线时的紧邻数字遮挡推断仍只用于普通品位；倚音 X、目标 X、和弦、跨弦或歧义线/弧仍拒绝。

滑音审计将 GP 内部的闷音占位品位统一为 `null`，与识别数据一致；开放弦 0 品仍是数值 0，不能与 X 混为一谈。导出器无需修改，已有 GP 回读验证能保留 dead 标志、连奏滑音类型和目标；截断来源或目标的分段导出仍拒绝。
