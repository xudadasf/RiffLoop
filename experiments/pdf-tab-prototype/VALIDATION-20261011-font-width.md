# 2026-10-11：按实际字形宽度恢复延音，《默》整曲核心验证

基线 `a4bd144`。继续独立离线 PDF 转 GP 实验，优先修复练习节奏。识别器只读取 PDF，不读取参考 GP，不修改或安装 Android/iOS。

## 原因与修复

《默》剩余七个节奏差异小节为 24、50、51、69、75、77、83。逐个渲染 PDF 后确认，缺失的延续音都有实际弧线和符干；其弧线末端至符干距离约 7.59 点。旧规则要求同页出现两处相同品位的括号数字，第 3 页有 `(12)` 却没有 `(19)`、`(20)`，第 4 页有 `(19)`、`(20)` 却没有 `(17)`、`(18)`，因此没有采用实际相同的排版宽度。第 24、69 小节缺少十六分延续音，第 77 小节缺少八分延续音，其余包含四分延续音或附点八分延续音。

现在直接读取 PDF 的逐字形边界，从括号标记中分离数字部分的宽度，只允许同页、同字体、同字号、数字宽度差不超过 0.1 点的样本参与测量。至少两个独立排版位置的留白测量必须一致。同一和弦里的两个数字不算两个独立位置；仍保留唯一入弧、同弦端点、唯一符干、连续小节和中间休止/起音检查。没有按缺拍数量补音，也没有把所有两位数字预设为等宽。

第 67 小节是另一个独立限制：延音和弦末端只印出一个括号音符，旧规则禁止向这种单个可见音符补充其他弦。现在只在该可见音符已确认从来源和弦延续、遗漏弦拥有独立弧线和实测留白证据时允许恢复。换品位、普通单音或未确认延音的括号音符仍不能触发。
