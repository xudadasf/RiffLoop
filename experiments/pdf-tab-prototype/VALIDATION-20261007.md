# 2026-10-07：提高整曲转换可靠性

本轮继续独立电脑端实验，没有修改或安装 RiffLoop Android/iOS。所有素材在本地处理，不调用大模型，不上传原谱。用户无需参与标注或逐小节核对。

## 实现内容

1. **图形音乐符号**：用仓库已有 Bravura 字体生成模板，识别 PDF 中转为轮廓的拍号、休止、音头、符尾和附点。模板来自字体，不来自 GP 答案；低相似度或有歧义时不接受。
2. **节奏**：恢复被加线干扰的五线谱关联；识别六线谱中的圆圈二分/全音符；按横向列数计算和弦附点；避免相邻符尾覆盖横梁给出的时值；支持 3/5/6/7 连音及部分变拍号。
3. **休止**：支持部分图形休止与附点休止。只有确认拍号、且谱面区域没有未知标记时，才把空白小节解释为整小节休止；3/4 等拍号按小节长度处理，不能固定填四拍。
4. **延音**：依据实际连接弧线、同弦同品及符干补出部分隐藏品位的延音。跨弦连奏、普通同品位弧线和括号本身不直接判成延音。导出时保留延音，并阻止缺少延音源的片段导出。
5. **结构保护**：拍号未识别、小节号缺失/重复/乱序、时值不完整时阻止相应导出。4/4 默认值只用于诊断，不再据此自动输出。
6. **自动验证**：增加配对一致性检查，并加入逐拍的音符、休止、延音与拍号比较。GP 序列化之后再次读取，核对音符、时值、延音、拍号、定弦和初始速度。

## 与初版的同素材对比

初版为提交 `164ef79` 的实验结果。两轮使用同一批 82 组候选素材，均有 50 组完成对比；14 组多分谱/重复小节号、4 组未找到六线谱、14 组参考 GP 读取失败。这些不支持或失败的素材没有从总量中隐去。

| 指标（完成对比的相同 50 组） | 初版 | 本轮 |
| --- | ---: | ---: |
| 识别音符匹配率 | 95.56% | 95.59% |
| 音符覆盖率 | 91.48% | 92.20% |
| 音符及节奏覆盖率 | 77.72% | 90.39% |
| 弦位/品位匹配音符数 | 25,476 | 25,677 |
| 音符及节奏匹配数 | 21,644 | 25,173 |

参考音符总数均为 27,850。41 组的音符或节奏匹配数增加、9 组持平，没有一组的上述匹配数减少。这不表示没有任何误识别，也不表示其他未测属性没有退步。

新增的核心小节检查通过 **3,260 / 4,391（74.24%）**。它严格比较第 1 声部逐拍音符、休止、延音、时长及拍号；有其他声部音符的小节不判为通过。整小节休止与原 GP 中空白整小节按相同的静音时长比较，不因存储表示不同而误报。该检查仍不包含全部技巧、反复、速度变化及音色。

本轮预测了 749 个延音目标，其中 748 个与参考配对匹配。参考数据共含 2,235 个延音目标，**覆盖仍不足**；未匹配的 1 个位于配对证据不足的素材中。不能把这一匹配比例当作任意 PDF 的识别置信度。

自动配对检查中，37 组得到文件名、小节覆盖和音符分布的一致性支持，13 组证据不足。全部 50 组仍进入上表，避免只挑好识别的素材。多轨 GP 在评估阶段选择匹配最多的轨道，因此结果也不是独立盲测。同一曲目不同分谱不算独立歌曲。

## 剩余边界

跨行/跨页延音、多声部、完整技巧、反复与中途变速仍未解决；初始 BPM 仍按四分音符解释。少数图形符号无法可靠区分，继续阻止导出而不是补拍凑满。两个原始 GP 文件仍无法由当前 alphaTab 导入，未更改原文件。

因此本轮是**可量化的可靠性改进**，不是通用 PDF → GP 转换已完成。继续保持独立实验，尚不接入正式软件。
