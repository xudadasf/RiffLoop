# 2026-10-16：跨页测量隐藏延音留白

基线 `39a9aed`，对照 [上一轮完整摘要](validation-summary-20261016-regression-loop.json)。本轮只修改独立 PDF 识别实验，没有修改应用、导出规则、参考素材或通过门槛。

## 原因与修改

从跨曲节奏问题队列检查发现：隐藏延音的宽度测量原先只使用当前页的可见括号数字。有些页没有足够样本，而同份 PDF 的其他页使用完全相同的字体资源、字号和六线谱间距，已有充分样本；因此真实存在的延音弧和符干未能被连接。

保留原来的本页测量规则，增加严格的跨页备用测量：实际字体资源编号相同，字号与谱线间距一致，至少两个独立排版位置、包含其他页的样本，而且所有可用留白测量一致。仅字体名称相同但资源不同的样本不混用。仍须有弧线、唯一目标符干、正确隐藏位置和连续节拍；遇到休止、冲突音符或不一致样本不补音。不根据参考 GP 或缺少的拍数猜测。

合成两页 PDF 的测试先在旧识别器上复现 3 项失败，再验证修改：支持样本在前页或后页；拒绝单样本、不同字体资源/字号/谱线间距、测量冲突、错误目标间距、缺失符干、可见冲突音符和中间休止。实际导出并回读 MIDI，确认延音持续两拍且不增加起音。
