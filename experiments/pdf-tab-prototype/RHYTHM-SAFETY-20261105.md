# 图片节奏识别与操作问题检查（2026-11-05）

## 根因与处理

- 图片数字定位与横梁端点有少量偏差时，原规则可能漏掉一条横梁，把十六分音符误读为八分音符。现在同时核对实际符干与每条横梁的横向位置。
- 细符干在截图和扫描中可能部分断裂。只在同小节、同一组横梁上还有另一根可靠且位置不同的符干时，才采用较弱的读取；它仍标为待核对。缺少佐证、方向歧义、位置不符时继续占位。
- GP 草稿和浏览器对照中的 `?` 包括默认占位及较弱的识别值；问题清单和 JSON 记录区分两者。未识别的剩余时长使用小节末尾的休止占位，增加提示要求检查原谱位置，不能将其作为已识别休止。
- 旧结果没有生成时的清理记录时，无法判断同名文件是否后来被用户改动，因此拒绝自动清理；已有原始记录的结果仍会按哈希保护被修改的文件。格式损坏的分区方案显示错误，不进入裁剪队列。
