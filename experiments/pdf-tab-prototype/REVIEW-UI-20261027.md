# 浏览器识别结果页

从桌面入口打开“查看结果”，或打开结果文件夹的 `review.html`。页面以 **打开 GP 草稿** 为主要入口，音符和节奏直接在 Guitar Pro 中修改、保存。页面只用于查看原谱、识别结果和问题说明，不再设置勾选或人工核对进度；页面上的操作不会重新生成 GP。

- 图片 / 扫描 PDF 的谱图支持点击放大、缩放、原始大小和 Esc 关闭。
- 可筛选程序标出的待修改项，按页码 / 小节搜索，定位下一处疑点。
- GP、原文件、修改清单集中在页首，普通 PDF 保留原谱识别标记入口；技术记录默认折叠。
- 窄窗口按小节纵向展示。中间图片清理后保留音符和问题说明，不显示失效的预览按钮。
- HTML 自带样式和脚本，无需服务器或联网，不依赖浏览器本地存储。

实现仅调整报告展示，未改变识别、时值推断或 GP 导出。问号占位、未采用的弦带、未确认内容与识别限制继续展示；没有标记不等于音符和节奏准确。

验证：`python -m unittest test_desktop_batch test_desktop_cleanup test_review_page -q`，18 项通过。使用 Edge 检查图片报告、152 小节 PDF、筛选和搜索、疑点定位、缩放、原始尺寸、Esc 与焦点恢复、390 px 窄窗口、清理后页面及失败页面。自动浏览器检查通过本机 HTTP 地址运行。

页面截图、浏览器检查脚本及已有结果页面备份位于 `D:\RiffLoop-model-tests\review-ui-20261027`，不加入仓库。旧页面有备份，刷新只更新 HTML；GP、识别数据与结果记录通过文件哈希核实未变化。
