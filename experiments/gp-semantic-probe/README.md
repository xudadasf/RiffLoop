# GPIF 音符候选只读实验

此实验只筛选非常受限的普通单音候选，不修改谱面、写入 GP 或接入应用。它验证音符各级引用唯一、调弦及移调信息与导入器观测一致；除下述受限 Tempo 外，不理解的引用、技法、自动化和多个未知属性会被保守拒绝。这些限制会排除大量合法乐谱。

轨道只接受目前检查过的名称、移调、谱表和下述单一初始音色结构；未分析的音效、和弦图等结构，以及下述受限 Tempo 之外的 Sound、SyncPoint 等自动化均拒绝。只读样例统计表明它们普遍存在，但目前证据不足以证明所有相关语义安全，不能把数量当作放宽条件的依据。

调用方必须将从相同归档提取的 GPIF 字节哈希随导入器观测一起提供。实验会拒绝哈希不一致的输入；哈希仅关联调用方提供的数据，不能证明观测确由导入器从该文件生成。实验还未对所有 GPIF 字段建立完整白名单，也不验证 ZIP 资源、音频、播放或外部软件显示；即便返回候选，也不能据此修改、保存或覆盖用户谱。

运行合成回归：`python -B -m unittest discover -s experiments/gp-semantic-probe -p 'test_*.py'`。测试不读取或输出用户乐谱。

本机按相对路径排序抽查 60 份开发素材，只读执行归档检查与候选筛选，没有任何一份得到通过筛选的候选：其中 6 份并非 ZIP，12 份因归档大小限制、多轨或其他读取原因未完成此筛选，其余 42 份被当前严格条件拒绝。大量开发谱包含尚未验证的轨道音色、速度自动化、伴奏或其他结构；这些是有意保守的限制，不代表这些谱一定不能编辑，也不代表所有 GP 文件的兼容率。

当前允许一类非常受限的 MasterTrack Tempo 事件：必须在第 0 小节位置 0 有明确事件，每小节最多一个，使用非渐变、整数 BPM 和节拍参考 `2`，并与调用方提供的逐小节读取器观测完整一致。缺少速度观测、读取器额外产生的隐式默认速度、SyncPoint／Sound、未知字段及单位均拒绝。谱面和读取器观测均没有速度事件时，仅供合成测试的空列表可以通过。实验观察桥传递读取器的速度快照；该变化不表示可以修改或保存真实谱。测试使用仓库合成夹具的内置读取器结果验证 BPM、位置、显示标记与类型。

单一初始音色仅接受一个已知字段结构的 MIDI 音色；其 Program 和由 MSB、LSB 组成的音色库必须与读取器观测一致。缺少观测、多个音色、动态切换、未知音效或其他轨道结构仍会拒绝。对仓库测试谱只单独验证了音色组件，该谱整体尚不符合候选条件；这不代表真实文件已可安全编辑。
