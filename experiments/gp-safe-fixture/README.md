# 固定测试谱的内存修改实验

只接受仓库内 `transport.gp` 的固定 SHA-256，且只构造一次固定的首音 A♯→B 修改。整个过程在内存中执行，不接受用户乐谱，不输出 GP 文件，也不接入正式程序。此实验用于探索保存方法，不能作为真实乐谱编辑器。

对于这份固定夹具，目标音符所在的 Bar、Voice、Beat、Note 引用均唯一；其 Rhythm 被其他节拍共用，本实验不修改时值。修改同时更新品位、MIDI、ConcertPitch 与 TransposedPitch：品位 3→4、MIDI 58→59、A♯→B；原始弦号、调弦、变调夹与记谱移调经测试核对。内置 alphaTab 重读该内存候选后，首音所检品位、音高和音名状态符合预期，其他选定的音符、节拍及元信息不变。

时间对照覆盖每拍的时值、附点、连音组参数、播放和显示起点及长度，以及每小节的名义起止刻度；全部 16 拍仍引用同一个未修改的 Rhythm。这些是模型计算的数据，不代表已检查实际音频。

此夹具的主谱是压缩包中最后的本地文件项，没有数据描述符。实验保留此前所有本地记录与压缩成员原始字节，仅重压主谱并更新其必要的 CRC、大小与中央目录偏移。测试逐项验证非主谱条目的中央目录原始字节、解压内容和元数据（包括 UTF-8 标志）不变；主谱仅目标音符片段不同。不能据此推断其它 ZIP 结构可使用相同方法；数据描述符、加密、其他布局、签名、共享音符和未知音高关系均未支持。

运行：`python -B -m unittest discover -s experiments/gp-safe-fixture -p 'test_*.py'`。当前测试没有检查用户谱、所有 GPIF 语义、声音、iPad 真机或 Guitar Pro 的打开和显示，也没有实现共享对象复制、时值与技巧编辑。因此，即便测试通过，也不能覆盖或生成真实用户谱。
