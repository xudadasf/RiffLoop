# 合成 GPIF 共享引用实验

这是一个不接收文件、完全在内存运行的研究实验。它模拟多个曲谱位置共用小节、声部、节拍和音符时，修改一个位置应如何逐层复制被共享的对象并更改引用，避免其他位置跟着变化。原始对象不被修改，共享节奏对象也不被改动。

运行：`python -B -m unittest discover -s experiments/gpif-safety-probe -p 'test_*.py'`。

实验只接受内部生成并带有标识的极简 XML，仅支持 `String`、`Fret`、`Midi` 三种音高属性，并要求由测试提供的空弦 MIDI 与当前音高严格对应。未知音高字段、连音、节拍技巧、引用缺失、重复 ID 和无效位置会被拒绝。

这不是 GP 读写器，不接收真实乐谱，也不输出 ZIP 或 GP 文件。真实 GP 还涉及调弦、变调夹、记谱与实际音高、转调、延音和技巧，以及未列出的附加资源；本实验没有验证这些关系、存档保真、时值修改、播放或 Guitar Pro 兼容性。不得据此接入编辑功能或覆盖真实乐谱。
