# 合成 GP 主谱非末尾布局实验

本实验只允许由代码在内存中生成的五种固定 ZIP 数据：使用仓库测试谱的固定 GPIF 内容，其他成员均为虚构内容，主谱之后另有资源成员。若输入与所选固定样本的每个字节不一致，立即拒绝；不读取用户谱，不创建 GP 文件，不接入正式程序。

覆盖的布局包括无数据描述符、正常大小顺序与反序大小描述符、有签名与无签名描述符，以及中央目录和本地文件排列顺序不同。修改只替换固定的首个测试音符，同时更新 CRC、尺寸、后续成员的目录偏移和 ZIP 结尾位置；其他成员的完整本地记录保持逐字节一致，中央目录仅允许必要的偏移变化。内置 `archive_guard` 会检查原始资源、成员元数据、描述符顺序和内容；反序大小的描述符仅在实验明确启用时允许。

运行：`python -B -m unittest discover -s experiments/gp-fixture-layout -p 'test_*.py'`。测试还使用 RiffLoop 内置 alphaTab 从内存重读合成存档，对照音符与时序快照。反序描述符的其它软件兼容性未验证；加密、ZIP64、多卷、签名、真实素材、共享音符、任意修改及文件写入均未实现。通过实验不能证明真实 GP 可安全编辑或覆盖。
